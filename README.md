# Fixed-Target Experiment

Python-проект для генерации модельных событий и хитов детекторов в эксперименте с фиксированной мишенью.

Проект предназначен для создания синтетических данных, которые можно использовать при разработке и исследовании алгоритмов реконструкции треков частиц.

## Возможности

- Генерация модельных событий и частиц.
- Моделирование прохождения частиц через детекторы.
- Симуляция хитов детекторов.
- Визуализация хитов и траекторий частиц.
- Экспорт данных для дальнейшего анализа.


## Исследование Парето

Ветка исследования добавляет воспроизводимый перебор GNN и декодеров, сравнение
с фильтрацией и без неё, отдельный тест и экспорт всех точек. См.
[описание протокола](experiments/pareto/README.md) и
[ноутбук Colab](notebooks/Tracking_Pareto_Colab.ipynb).

Генератор в этой версии исправлен; старые графики не считаются воспроизведёнными.
Точное прежнее состояние сохранено в истории Git. Для новых запусков используйте
фиксированный коммит и сохраняйте manifest среды.
