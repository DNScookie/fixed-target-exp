# Fixed-Target Experiment

Python-проект для генерации модельных событий и хитов детекторов в эксперименте с фиксированной мишенью.

Проект предназначен для создания синтетических данных, которые можно использовать при разработке и исследовании алгоритмов реконструкции треков частиц.

## Возможности

- Генерация модельных событий и частиц.
- Моделирование прохождения частиц через детекторы.
- Симуляция хитов детекторов.
- Визуализация хитов и траекторий частиц.
- Экспорт данных для дальнейшего анализа.
